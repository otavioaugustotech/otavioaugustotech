## 🚀 Projetos

### 🥬 Feira System — Sistema Web de Gestão para Feirantes

Meu projeto de conclusão de curso do Técnico em Informática, desenvolvido em equipe no Instituto de Tecnologia de Jacareí.

O Feira System é um sistema web de gestão interna para feirantes, ambulantes e pequenos comerciantes. Seu objetivo é ajudar a organizar as informações e facilitar o acompanhamento dos resultados do negócio.

**Principais funcionalidades:**

* 📦 Cadastro e gerenciamento de produtos.
* 📊 Controle de estoque.
* 💰 Registro e histórico de vendas.
* 🗑️ Registro e acompanhamento de desperdícios.
* 🎯 Definição e acompanhamento de metas.
* 📈 Indicadores e relatórios.
* ♿ Recursos de acessibilidade.

**Tecnologias do projeto:** React, Vite, JavaScript, HTML, CSS, Node.js, Express e PostgreSQL, entre outras ferramentas e bibliotecas.

🔗 [Acessar o repositório do Feira System](https://github.com/otavioaugustocardosodossantos-debug/TCC-FEIRA-SYSTEM-)

### 🎧 AuraStud — Projeto em fase de documentação

O AuraStud é uma ideia de aplicativo e plataforma web voltada à organização dos estudos e à criação de experiências de aprendizagem.

A proposta é reunir materiais, resumos, anotações e conteúdos de estudo, com a possibilidade de incorporar recursos de áudio e Inteligência Artificial.

**Estado atual:** estou trabalhando na documentação e no planejamento do projeto. Ainda não comecei a implementação do sistema.

**Objetivo futuro:** transformar a documentação em uma aplicação funcional, planejada com cuidado e desenvolvida por etapas.
